## 4. 追踪规则

- 新增功能需求必须同时新增至少一个测试 ID。
- 删除/改变规则 ID 必须更新技术规范、测试计划和本矩阵。
- 测试不能以“某日志出现”为唯一证据证明 G-001；必须观察 tool spy 或 Agent Loop 执行计数。
- D0 文档允许测试状态为“未执行”；任何实现发布候选不得存在未覆盖 FR。
